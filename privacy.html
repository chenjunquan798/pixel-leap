隐私与无障碍说明

像素跳跳乐 Pixel Leap v2.0 · 更新于 2026-10-20

一句话：我们不知道你是谁，也没有任何服务器可以记录你。

这是一个纯静态网页。它不发分析请求、不加载第三方脚本、不写 Cookie、不读设备指纹。你的最高分只存在你自己的浏览器里。

1. 我们不收集什么

  • 不收集姓名、邮箱、头像、通讯录、位置——游戏里根本没有这些输入框。
  • 不使用 Cookie、本地存储追踪 ID、设备指纹或广告标识。
  • 不接入任何第三方分析、广告、社交 SDK；页面运行时的网络请求数为 0。
  • 不自动发帖、不自动分享。分享只在你自己按下按钮时发生。

2. 保存在你浏览器里的东西

只写入 localStorage 的一个键 pixelLeap.v2，内容如下：

数据用途保留期
最高分菜单与结算页展示、破纪录判断直到你清除站点数据
静音设置记住你的声音偏好同上
语言中文 / English 切换同上
累计局数、累计星星、最近游玩时间本机统计趋势；不出设备同上
会话计数（30 分钟无操作为新会话）Plan B 的回访代理指标同上
本地局记录（最近 200 条）只在本机统计局数、分数趋势与到达区域；用于开发自测同上

这些数据不出设备。你可以随时在浏览器「站点设置 → 清除数据」里删掉；想自己看一眼，按 F12 打开控制台执行 PixelLeap.exportLedger() 即可得到完整 JSON（不联网）。如果浏览器禁止本地存储（例如部分隐私模式），游戏会提示「本地存档不可用」，本局仍可正常游玩，只是刷新后不保留最高分。

3. 分享时会发生什么

  • 只有在刷新最高分时才会出现「分享成绩」按钮。
  • 点击后优先调用系统分享面板（Web Share API）；如果你的浏览器不支持，或你取消了分享，游戏会把一段文案和链接复制到剪贴板，并给出提示。
  • 分享链接只带一个 ?ref=share 参数用于区分来源，不含任何玩家标识。
  • 不自动发帖、不读取你的联系人或社交账号。

4. 关于分析（Plan B）

本项目采用 PRD 定义的 Plan B：完全关闭网络上报。没有事件端点，没有 Cookie，也没有队列重试。开发与运营只通过本地记录、人工测试与 GitHub issue 了解问题。因此本页不会出现「我们可能会与合作伙伴共享数据」这类句子——因为没有合作伙伴，也没有数据。

5. 无障碍说明（含已知边界）

目标是无障碍标准 WCAG 2.2 AA 的核心 UI部分：

  • 菜单、开始、暂停、继续、重开、结算、分享都是真实按钮，可以用 Tab / Enter / Space 走完整个流程，焦点始终可见。
  • 开始、暂停、恢复、结算通过 aria-live 播报，结算包含分数、高度、星星、最高分与新纪录状态；不会逐帧播报。
  • 支持系统「减弱动效」：关闭屏幕震动、粒子减半、区域过渡即时；不会因此静音。
  • 文字对比度按 4.5:1 设计，HUD 在夜幕 / 霞光 / 深空三种背景下均可读。

已知边界：Canvas 里的平台、星星与角色无法被屏幕阅读器逐项描述，因此完全非视觉的玩家目前无法独立完成核心跳跃循环。我们不把这一点包装成「已完全无障碍」。更完整的音频辅助模式属于后续版本，需要单独的用户测试。

6. 儿童与内容

游戏内容全年龄，没有文字聊天、没有用户生成内容、没有付费与广告，也不做儿童定向投放，不收集年龄或学校信息。

7. 变更

如果采集范围发生变化，会更新本页的版本号与日期，并在更新说明中标注。当前版本 v2.0（2026-10-20）与游戏内实际行为逐项一致：没有网络上报。

English summary

Pixel Leap is a static, single-page game. It sets no cookies, loads no third-party scripts, and sends no analytics: your best score, mute setting, language and a small local run log live only in your browser's localStorage. Sharing is always user-initiated and the link contains no personal identifier. The core UI is keyboard accessible with visible focus and live-region announcements; in-canvas sprites are not described to screen readers, which we state openly rather than claiming full accessibility.
